# 中文市场引擎（cn）细节

这份是从 SKILL.md 拆出来的引擎专属知识。**只在做中文市场分析时读。**
用法入口见 SKILL.md 的「选择市场引擎」。

## 七-C、中文引擎怎么工作

```bash
python3 scan.py --engine cn "关键词"
```

**需求** = 360搜索「相关搜索」词（真实搜索行为，高购买意图词可数）
**供给** = 搜狗微信文章存量 + 标题信号

## 八-C、三类一票否决（每条都有真实反例）

### ① 免费白嫖词 → 用户不是要工具，是要免费

相关搜索出现《永久免费版》《在线免费》《破解》。

**真实反例：`录音转文字`**
供给侧看是完美方向：微信仅 1000 篇（低供给），标题里 **4 条「已有付费工具」
信号**。只看供给会判满分。
但相关搜索是《录音转文字永久免费版》《豆包录音转文字在线免费使用》。
**这是价格战，不是需求。** 评分 10 → 3。

规则：≥4 条免费词封顶 3 分，≥2 条封顶 6 分。

### ② 垄断品牌词 → 该搜索词已被占死

相关搜索出现具体产品名（豆包、讯飞、剪映、鲁青、金蝶…）。
用户在找**那个产品**，不是找解决方案。

**真实反例：`试卷排版`** 9 条高意图词里 3 条是《鲁青答题卡制作工具》。

规则：出现即封顶 4 分。

### ③ 壁垒归零 → 你做完守不住

微信标题出现 `vibecoding`、`我自己做了`、`源码`、`一行代码`。

**真实反例：`房贷提前还款计算器`**
相关搜索里 **6 条高购买意图词，需求看起来很旺**。但标题里躺着
《一天时间 vibecoding 实现房贷提前还款计算器》。
**需求旺 + 壁垒零 = 你进去就是给别人做嫁衣。**

最危险的陷阱：所有需求指标都亮绿灯，只有这一个信号在报警。
规则：出现即封顶 3 分。

### 中文特有的分类陷阱

**B2B 的价格词是正信号，别误伤。**《收费价目表》《报价明细表》《费用》《成本》
在 B2B 语境下是**强购买意图**（用户在评估预算），不是白嫖。

## 九-C、中文引擎的限流防护（重要）

**搜狗微信连续请求会静默返回空页面，而不是报错。** 如果不处理，工具会把
"没抓到数据"误读成"存量 0 篇"，得出**完全相反**的结论。

脚本已内建：
- 空响应退避重试（25s / 50s），**不当作 0**
- 始终取不到时输出 `🟡 黄(不完整)` 并加否决项，**绝不给绿灯**
- 实测限流约 45 秒解除

**看到「黄(不完整)」就隔几分钟重跑，不要将就。**

## 十-C、中文引擎校准锚点

存量阈值（最常用的一条）：**1,500 篇以下才值得看，3,500 篇以上基本没戏。**
参照点：`摸鱼` 8580 / `AI写作` 5887 / `公众号排版` 4100 / `去重工具` 2009 /
`录音转文字` 1000 / `发票批量导出` 614 / `代账对账单` 511。

逐方向的完整分数见 `references/calibration.md`。

## 十一-C、中文引擎的付费验证（人工，10 分钟）

扫描能证明「需求旺 + 供给少」，但**证明不了有人真的掏过钱**。

去**闲鱼**搜该关键词，记录：

```
关键词：
有没有人在卖同类产品/服务：有 / 无
价格：
成交/想要数：
评价原文：
```

判读：
- **有人卖且有成交** → 直接开做
- **有人卖但无成交** → 需求可能是伪的，或定价错了
- **没人卖** → 换更窄的关键词重扫

为什么是闲鱼：它是唯一能看到**真实成交**的地方。搜索量是意图，成交是事实。
