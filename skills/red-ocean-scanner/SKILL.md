# 避红海扫描 · Red Ocean Scanner

## 一句话原则

**存量少不等于机会，存量少可能只是没人关心。** 判断必须同时看需求和供给，
而且**需求侧的"愿不愿意掏钱"比供给侧的"有没有人做"更重要**。

这个 skill 的存在就是为了防止一个具体错误：**只看供给就下结论。**
下面所有规则都是从真实反例里总结的，不是理论。

## 一、跑扫描

```bash
# 脚本就在本 skill 目录内，用相对路径即可
python3 red_ocean_scan.py "关键词1" "关键词2"
python3 red_ocean_scan.py --report 报告.md "关键词"
```

如果已按 README 安装，完整路径为 `~/.claude/skills/red-ocean-scanner/red_ocean_scan.py`
或 `~/.dsh/skills/red-ocean-scanner/red_ocean_scan.py`。

纯 Python 3.8+ 标准库，**无需 pip install，不需要 API key**。

输出是裁决，不是数据：

```
🟢 代账公司对账单    绿    8/10
供给  微信 511 篇 [低]
      标题信号: 教程/怎么用×2 | 纯内容/观点×1
需求  高购买意图长尾 2 条:
        ★ 代账公司内账报价明细表
        ★ 代账公司收费价目表
依据
      + 标题以教程为主 → 需求真实但没人做出好工具，是缺口
下一步  去闲鱼搜该词，看有没有人在卖同类服务、价格、成交数。
```

一次别超过 6 个词。**每个词要打两个数据源，间隔至少 6 秒**，脚本已内置冷却。

## 二、怎么读裁决

| 裁决 | 分 | 含义 | 动作 |
|---|---|---|---|
| 🟢 绿 | 8–10 | 值得投入一周验证 | 去做付费验证，别急着写代码 |
| 🟡 黄 | 5–7 | 有硬伤 | 换更窄的关键词重扫，或只当引流工具 |
| 🔴 红 | 0–4 | 别做 | 放弃，**不要靠加功能挽救** |
| 🟡 黄(不完整) | — | 数据没取全 | 隔几分钟重跑，**不要在这个结论上做决定** |

**「否决项」比分数重要。** 出现任何一条否决项，无论分数多高都要停下来。
否决项是「这个方向从结构上就不成立」，不是「需要努力克服」。

## 三、三类一票否决（核心知识）

这三类是真实踩过的坑，每一条都有一个反例支撑。

### ① 免费白嫖词 → 用户不是要工具，是要免费

相关搜索里出现《永久免费版》《在线免费》《破解》这类词。

**真实反例：`录音转文字`**
供给侧看是完美方向：微信只有 1000 篇（低供给），标题里 **4 条「已有付费工具」
信号**。只看供给会判满分。
但相关搜索是：《录音转文字永久免费版》《豆包录音转文字在线免费使用》。
**这是价格战，不是需求。** 用户已经在拿它跟免费产品比价，你进去就是白干。

规则：≥4 条免费词直接封顶 3 分，≥2 条封顶 6 分。

### ② 垄断品牌词 → 该搜索词已被占死

相关搜索里出现具体产品名（豆包、讯飞、剪映、鲁青、金蝶…）。
用户在找**那个产品**，不是在找解决方案。你做的不是"更好的选择"，是"用户没听过的
替代品"。

**真实反例：`试卷排版`** 9 条高意图词里 3 条是《鲁青答题卡制作工具》——
需求确实旺，但关键词已被占位。

规则：出现即封顶 4 分。

### ③ 壁垒归零 → 你做完守不住

微信标题里出现 `vibecoding`、`我自己做了`、`源码`、`一行代码`。

**真实反例：`房贷提前还款计算器`**
相关搜索里 **6 条高购买意图词，需求看起来很旺**。但标题里躺着
《一天时间 vibecoding 实现房贷提前还款计算器》。
**需求旺 + 壁垒零 = 你进去就是给别人做嫁衣。**

这是最危险的陷阱，因为所有需求指标都亮绿灯，只有这一个信号在报警。
规则：出现即封顶 3 分。

## 四、最容易犯的错：把限流当成「无人竞争」

**搜狗微信连续请求会静默返回空页面，而不是报错。** 如果不处理，工具会把
"没抓到数据"误读成"存量 0 篇"，得出**完全相反**的结论。

脚本已内建防护：
- 空响应会退避重试（25s / 50s），不当作 0
- 始终取不到时输出 `🟡 黄(不完整)` 并加否决项，**不会给绿灯**
- 实测限流约 45 秒解除；连续快速请求会立刻再次触发

**看到「黄(不完整)」就隔几分钟重跑，不要将就。**

## 五、数据源边界（实测，别浪费时间重试）

| 源 | 用途 | 状态 |
|---|---|---|
| **so.com（360搜索）** | 相关搜索 = 真实需求长尾 | ✅ 可用，已接入 |
| **weixin.sogou.com** | 微信存量 + 标题信号 | ✅ 可用，有严格限流 |
| 新榜/千瓜/蝉妈妈/站长指数 | 分平台数据 | ⚠️ 首页可开，数据要付费 |
| Bing / 百度 / 头条 / 神马 | — | ❌ 套话或 JS 空壳 |
| 知乎 / B站 / 小红书 / 抖音 / 闲鱼 | — | ❌ 403 / 412 / 登录墙 |

**小红书、抖音、闲鱼无法程序化访问，不要尝试绕过。** 这不影响判断：
它们只能说明"有多少人在聊"，不能说明"有多少人在卖"。
红海的硬数据在 360 + 搜狗微信，这两个足够。

## 六、最后一道验证：付费意愿（人工，10 分钟）

扫描能证明「需求旺 + 供给少」，但**证明不了有人真的掏过钱**。这一步必须人工。

去**闲鱼**搜该关键词，记录：

```
关键词：
有没有人在卖同类产品/服务：有 / 无
价格：
成交/想要数：
评价原文：
```

判读：
- **有人卖且有成交** → 直接开做，你只需要做得更好或更便宜
- **有人卖但无成交** → 需求可能是伪的，或定价错了
- **没人卖** → 回到需求侧换更窄的关键词重扫

为什么是闲鱼：它是唯一能看到**真实成交**的地方。搜索量是意图，成交是事实。

## 七、盲点扫描（每次分析都要过一遍）

这些不出现在任何平台清单里，但决定同样的努力能换多少钱：

1. **「有人做但做得烂」永远比「没人做」值钱。** 没人做常常是因为不赚钱。
2. **钱在重复收费里。** 订阅 > 买断 > 广告分成。内容平台分成是最差的一档。
3. **买家要选「正在赚钱的人」**（卖家、代账公司、从业者），不是「想赚钱的人」
   （同行、小白）。前者算得清 ROI，后者是焦虑税且窗口在关。
4. **分发先于产品。** 先答"用户怎么找到我"，再做产品。靠搜索的方向才适合
   没有粉丝、没有人脉、不投广告的人。
5. **不用登录/版号/备案的形态优先**（网页工具、浏览器插件、桌面买断），
   把合规成本压到零。
6. **AI 含量越高的环节越不值钱。** 内容生产已被 AI 打平；判断、信任、合规
   这些 AI 做不了的环节在升值。
7. **平台补贴窗口**是个人能拿到的最高时薪，但很短，看到就冲。

## 八、校准锚点（用于判断你的直觉准不准）

以下为实测值，可直接对照：

| 方向 | 分 | 裁决 | 卡在哪 |
|---|---|---|---|
| 代账公司对账单 | 8 | 🟢 | — |
| 淘宝标题优化 | 8 | 🟢 | — |
| 发票批量导出excel | 6 | 🟡 | 少量免费词 |
| 试卷排版工具 | 5 | 🟡 | 鲁青已占位 |
| 公众号排版 | 5 | 🟡 | 4100 篇高供给 |
| 录音转文字 | 3 | 🔴 | 免费白嫖 + 豆包 |
| 图片批量加水印 | 3 | 🔴 | 免费白嫖 |
| 房贷提前还款计算器 | 3 | 🔴 | 壁垒归零 |

供给存量参照：`摸鱼` 8580 / `AI写作` 5887 / `公众号排版` 4100 /
`去重工具` 2009 / `录音转文字` 1000 / `发票批量导出` 614 / `代账对账单` 511。
**1500 以下才值得看，3500 以上基本没戏。**

## 九、标准工作流

1. 列 6–10 个候选关键词（从自己的抱怨、身边人的抱怨里找）
2. 跑扫描，拿到红黄绿排名
3. 只对绿灯项做闲鱼付费验证
4. 按盲点清单复核一遍绿灯项
5. 只留一个，花一周做落地页，**不写产品代码**
6. 判断标准：有没有陌生人在 6–8 周内主动掏钱

**不要跳过第 3 步。** 扫描再准也只是意图数据，成交才是事实。
