# 关键词实测数据（需求 + 供给双测）

用 `red-ocean-scanner` 的 `red_ocean_scan.py` 实测，2026 年。
**这是公开可复现的数据，不是估算**——用同一个脚本可以重跑验证。

想生成**当前时点**的同格式数据（含否决项、依据、下一步）：
`python3 scripts/remeasure_cn.py`。它会先探一次供给侧，确认搜狗微信没被
IP 封锁再开跑——封锁期间每个请求都返回壳页，不预检就会写出一份大半
没有供给侧的文档。

两个独立数据源交叉验证：
- **需求** = 360搜索的「相关搜索」词（真实搜索行为）
- **供给** = 搜狗微信的文章存量 + 标题信号（供给侧的性质）

评分 0–10 = 供给 3 分 + 供给性质 3 分 + 需求 4 分。

> 存量数字会随时间变化，评分也可能小幅波动。但**判读结论（红/黄/绿）是稳定的**，
> 因为它们由市场结构决定，不由具体数字决定。

## 二、这次实测最重要的发现：光看存量会看错

**`录音转文字` 和 `图片批量加水印` 是完美的反例。**

看供给侧，它们是最诱人的方向：存量都只有 1000 篇（低供给），标题里各有 4 条
「已有付费工具」信号。按我第一版的判读规则，这两个都是 10 分满分。

但看需求侧的相关搜索词，真相相反：

```
录音转文字 → 录音转文字在线免费 / 录音转文字永久免费版 / 豆包录音转文字在线免费使用
图片批量加水印 → 图片批量加水印免费工具免费版 / 批量加水印软件免费 / 在线制作免费
```

**用户不是在找工具，是在找免费替代品。** 这是一个已经打到价格归零的市场，
而且豆包这类免费产品已经进场。进去就是白干。

结论：**供给侧只能告诉你"有没有人做过"，需求侧的相关搜索词才告诉你
"这些人愿不愿意掏钱"。** 只看存量必然踩坑，这是这份表最大的方法论价值。

## 三、这份数据推翻/修正了原清单的哪些判断

**① 公众号排版工具（原推荐第 2 名）→ 放弃，确认。**
4100 篇落在红海边缘，标题清一色《完全指南》《超全指南》没有一条是工具。
相关搜索里只有 2 条高意图词，且都是《免费公众号排版工具》——用户要的是免费。

**② 房贷提前还款计算器（原推荐第 5 名）→ 放弃，确认。**
相关搜索里 6 条高购买意图词，需求看起来很旺。但标题里躺着
《一天时间 vibecoding 实现房贷提前还款计算器》——**需求旺 + 壁垒零**
= 你进去就是给别人做嫁衣。这是"需求好"最危险的陷阱。

**③ 发票 PDF 批量提取（原第 1 名）→ 确认，但不再是唯一首选。**
614 篇、付费工具信号 ×2、7 条高购买意图长尾（含《批量pdf电子发票提取到excel
工具》《发票识别导出excel免费软件》）。市场已验证，可以做。
但被 2 条免费词拉低到 6 分，说明有免费方案在竞争，你要靠"本地处理、不联网、
数据不出电脑"这个差异点打，而不是靠便宜。

**④ 新增：代账公司对账单（8 分，本次第一）**
511 篇，零付费工具信号，标题只有教程和观点。相关搜索里出现
《代账公司内账报价明细表》《代账公司收费价目表》——**用户在算预算**，
这是 B2B 强购买意图。买家是"正在赚钱的人"（代账公司），不是"想赚钱的人"。
本次实测里最干净的缺口。

**⑤ 新增：淘宝标题优化（8 分）**
596 篇且付费工具信号 ×2，这个组合很少见。买家是卖家，算得清 ROI。

## 四、下一步

**只剩一件事要做：去闲鱼验证付费意愿。**
上面全部是"需求旺不旺 + 供给多不多"，最后一道验证是"有没有人真的掏过钱"。

去闲鱼搜这三个词，10 分钟：
1. `代账 对账单`
2. `淘宝标题优化`
3. `发票 批量 提取`

看：有没有人在卖、卖多少钱、成交几单、评价怎么说。
**有人卖且有成交 = 直接开做。没人卖 = 回到需求侧重新取样。**
